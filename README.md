# Userscripts

A collection of custom userscripts.

## Scripts

- **[Nyaa MAL Link & Poster](./nyaa_mal)**: Displays MyAnimeList links, score, and anime poster on Nyaa torrent pages.
- **[HN Parent Comment Preview](./hn_parent_preview/hn_parent_preview.user.js)**: Shows a popup preview of the parent comment when hovering or focusing `parent` links on Hacker News.
- **[BookWalker Viewer Force Black Background](./bookwalker/bookwalker.user.js)**: Intercepts BookWalker two-page split fills and sets background to pitch black.
